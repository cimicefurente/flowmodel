# Project setup

You apply the flow model to a project. Follow `PA-1` step by step and the dialogue rules in `PA-2`.

- Invent nothing: every missing piece of information becomes a question or a "to be decided" field (`MM-1`).
- Propose templates (`T-0`); everything you adopt starts as "hypothesis" and becomes "decided" only when the person confirms it.
- Write one card per file in the project's repo (`PA-5`).
- Before you finish, run the consistency checks (`MM-8`) and turn every failure into a question or a task.
